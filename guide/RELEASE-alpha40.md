# 停一下 v0.2.0-alpha40-dev · 开发预览版

这是当前已交付 APK 的公开预览下载，不是新构建或正式上架版本。versionCode 41，最低 Android 10（API 29），主要在单台 Android 16 手机验证。

## 下载与开始

下载附件 `tingyixia-0.2.0-alpha40-dev.apk`，使用前阅读[使用说明](https://github.com/markgfu/PauseCN/blob/master/guide/USAGE.md)。首次建议不开 AI，只选择两三个应用体验。APK 不附带开发者 Key 或手机数据。

这个文件是可调试的 **Debug APK**；GitHub Release 标为 **Pre-release** 不会改变其构建性质。只连接可信的调试电脑。与此前同来源 alpha40 的 APK 完全一致，已安装者不必更新。

## 这一版能做什么

- 打开目标应用前停几秒，自主选择离开或带着理由继续。
- 本地常用理由、自定义应用分类、前台时长估算、热力图与日周报。
- 可选 DeepSeek：自定语气、画像与记忆、按授权预生成下次提醒、交流建议、使用解读和分类建议。
- 分享图片模板可加入已有 AI 解读；设置建议需要确认后才修改。

## 费用与隐私

AI 默认关闭。开启后使用自己的 API Key，请勿共用或提交到反馈中。每次请求可能收费；失败、取消或超时也可能已计费。个性化预生成开启后可能继续自动请求，应用不设每日生成总数或费用硬上限。

本地采集与发送 AI 分开授权。不要公开私人报告、备份、完整系统日志或未遮挡的截图。自动昨日复盘默认关闭，初次试用建议保持关闭。

## 已知限制

- 部分系统可能拦截安装或撤销无障碍权限，原因仍未解决。遇到风险提示先停止，不关闭系统防护、不绕过拦截。
- 未覆盖不同品牌 ROM；Android 10+ 是安装门槛，不是所有设备的兼容保证。
- 前台时长是目标应用估算，不是全机屏幕时间。停顿次数不等于全部启动次数，缺失不等于零。
- AI 设置建议的真实设备应用/撤销闭环尚未完成验证。AI 可能误解记录，不是心理诊断。
- 自动复盘有一次自然调度成功记录，不保证每日准时完成。
- 签名不同可能无法覆盖安装；不要为解决冲突而直接卸载，卸载会丢失本地数据。
