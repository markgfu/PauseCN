# 停一下：使用说明

## 第一次使用

1. 在 Android 10 及以上设备安装可信来源的开发包。遇到系统风险拦截先停止，不绕过防护。
2. 阅读应用内权限和数据说明；当前入口要求已满 14 周岁。
3. 从统一权限页进入系统设置，由本人开启“停一下 · 打开前干预”无障碍服务。
4. 在“目标”选两三个想试用的应用，先预览，再从桌面打开体验。电话、支付等关键操作期间不要测试。
5. 停顿后可以离开，也可以选理由、补充文字并确认继续。临时通行期间不会重复停顿。

等待时间、临时通行和生效时段目前是全局规则。目标页支持全选/取消全选，作用于当前匹配范围。分类支持自定义名称与单个/批量修改，一个应用一个主分类；历史记录按当前分类重新分组。

## 时长和报告

查看时长需要同时开启应用内“本地使用时长分析”和系统“使用情况访问”。不需要时可以跳过。

从启用、选入或重新授权后开始采集，不补录全部历史。正常使用目标应用后再看记录。数据是目标应用前台估算，可能受漏采、中断和保留期影响，也可能与停顿层重叠。停顿次数不是全部打开次数。

记录页可查看热力图、日周报并分享图片。“更新分析依据（本地）”只更新统计，不调用 AI。分享模板可加入已有 AI 解读；先看预览再选接收应用。隐藏应用名不会自动删除解读原文中的私人信息。

## 可选 AI

在“AI陪伴 → 连接与风格”配置自己的 DeepSeek API Key。不要把 Key、密码发给开发者或贴到反馈截图里。未开启 AI 时基础功能仍可使用。

- 普通句库按风格生成，需要查看并确认应用；手写句子优先。
- “我的背景与下次提醒”独立授权，已预生成的有效短句可以直接用于下次停顿，不等待联网。
- 个性化开启后，真实继续或离开可能自动准备下次句子，持续使用可能持续计费。应用没有每日费用硬上限。
- 本地采集不等于允许发送 AI。查看每项功能的发送范围；交流中不要输入不愿交给服务商的内容。
- 记忆可以查看、确认、纠正和忘记；关闭交流保存与关闭记忆使用是不同设置。
- 分类与设置建议先看结果再确认。设置建议真实设备应用/撤销闭环仍未完整验证。
- 自动昨日复盘默认关闭，初次试用建议保持关闭。系统后台调度可能延迟；失败不自动重试同一天，手动重试可能再次收费。

失败、取消或超时也可能已经计费。AI 可能误解记录，不必为验证而反复生成。

## 数据、反馈和退出

继续理由按每个应用使用次数排序，同次数按最近使用排序。忘记理由会删除相应历史理由文字，保留选择结果计数。

清除历史与完整重置影响不同：独立偏好和 Key 在清除历史时保留，完整重置会一并删除。加密导出不是导入恢复功能；不要上传私人备份。已分享或已发送服务端的数据不会随本地删除撤回。

反馈只需：应用版本、手机型号和 Android 版本、操作步骤、预期与实际结果。截图先遮挡私人内容，不需要 Key、完整日志、使用历史或备份。

退出试用时，可关闭自动复盘、个性化预生成或 AI，并在系统中关闭无障碍和使用情况访问。卸载会删除应用本地数据，不会自动删除外部分享/导出文件。不要为解决签名冲突而贸然卸载。
