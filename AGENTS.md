# Project contribution attribution

- Preserve the maintainer's Git author identity. For commits that Codex materially helps produce, add this commit-message trailer after a blank line:

  ```text
  Co-authored-by: Codex <noreply@openai.com>
  ```

- This format is used in the official `openai/codex` repository, for example https://github.com/openai/codex/commit/60b45d92d9fc9af8337182839f3d5989a859c333.
- Only credit actual participation; do not add AI attribution to unrelated human-only work or impersonate an unrelated GitHub account.
- Do not rewrite published history or move release tags merely to backfill attribution without explicit user authorization.
- AI attribution does not imply OpenAI ownership, official maintenance, endorsement, or a guarantee that GitHub will show a contributor avatar. Keep the explicit README contributor credits accurate.
